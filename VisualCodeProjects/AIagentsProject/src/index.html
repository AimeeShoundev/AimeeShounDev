THE BASICS

What is an AI agent?

TRADITIONAL AI

You ask.
It answers.

What meetings do I have tomorrow?
You have meetings at 9 AM, 11 AM and 2 PM.
AI AGENT

You give it a goal.
It works through the task.

Help me prepare for tomorrow.
✓ Check calendar
✓ Review meetings
✓ Gather information
✓ Build summary
✓ Create task list

An AI agent combines reasoning, instructions, tools and memory to work toward a goal.

Send instructions to a model and display its response.

LEVEL 03

Add a tool
