Use the updated portfolio
1. Replace index.html, style.css and script.js in your existing portfolio folder.
2. Keep all three filenames exactly as shown, in the same folder.
3. Keep your existing assets folder. The resume link still points to
   assets/Aimee-Shoun-Resume.pdf. Original project images are used when available.

   No build, installation or API key is required.
