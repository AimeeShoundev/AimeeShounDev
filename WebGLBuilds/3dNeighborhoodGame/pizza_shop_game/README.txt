PIZZA SHOP — WALK BEHIND THE COUNTER

CHANGED: Removed the front checkout counter movement barrier. You can now walk behind the counter toward the pizza station. The pizza-prep counter still has collision.

Extract this ZIP first. Open the pizza_shop_game folder in VS Code and run: npx serve .
Or double-click START_GAME_WINDOWS.bat if Python is installed.

WASD / arrow keys: Walk
Left mouse drag: Look around
Mouse wheel: Zoom
Enter / E near pizza station: Open pizza maker

The pizza shop GLB geometry has not been altered.
