BABY CARE TRACKER
Open index.html in Chrome, Edge, Safari or Firefox. No installation, server, account, or internet connection required.

Files:
index.html - all page elements
style.css - responsive page styles
script.js - timers, records, WebGL background, backup/export
assets/mother.png - selectable breastfeeding illustration
assets/poop.png - yellow-stripe smelly diaper
assets/pee.png - blue-stripe diaper
assets/both.png - blue-stripe smelly diaper
assets/nap.png - sleeping baby

Breastfeeding: Tap L or R to start; tap the same side to pause; tap the opposite side to switch. Press End Feeding Session to save the whole session, with each side's timestamps and durations.
Diapers: Each button records the exact current local date/time immediately.
Naps: Start Nap and End Nap record the interval.
History: Select a date, review entries, and delete accidental entries with X.
Exports: CSV for spreadsheets, JSON for full backup; Restore JSON replaces existing data.

Data is saved in browser localStorage on this device and browser. It will not sync between devices. Clearing browser data/private browsing may erase it. Export JSON backups frequently. Keep the folder structure intact.

This is a personal logging tool, not a medical device. Device clock changes can affect timestamps and running durations.
