HOUSE WALKAROUND — FIXED GLB EDITION

The 3D model is PRE-CONVERTED from the uploaded House_Level.fbx to assets/house.glb.
No browser FBX conversion is needed. The original FBX is also included for reference.

Deploy: upload the CONTENTS of the House_Walkaround folder to the SAME directory that hosts your existing page (index.html, script.js, style.css, assets/house.glb).
Do not upload only index.html. The assets/house.glb path must remain intact.

Controls: W/A/S/D or arrow keys move. Drag mouse to look. Shift runs. R resets.
Mobile: on-screen directional pad and drag elsewhere to look.

Note: The original FBX references external texture image paths that were not embedded in the supplied FBX file. The converted GLB retains geometry and approximate colors but cannot restore missing original textures.

This viewer is not connected to your multiplayer server. It does not change any URLs or backend configuration. Uses Three.js from CDN and requires internet connection.
